# 🌿 Plant Nursery E-Commerce Website

A full-stack e-commerce platform for a plant nursery selling 
plants, seeds, indoor/outdoor plants and gardening tools.

## Features
- User Registration and Authentication (JWT + bcryptjs)
- Product catalog for plants, seeds and gardening tools
- AI-powered chatbot for customer interaction
- Payment integration using Stripe
- Email notifications using Nodemailer
- REST API built with Express.js
- MongoDB database for data storage

## Tech Stack
- Frontend: HTML, CSS, JavaScript
- Backend: Node.js, Express.js
- Database: MongoDB (Mongoose)
- Authentication: JWT, bcryptjs
- Payment: Stripe API
- Email: Nodemailer

## Setup
1. Clone the repository
2. Run npm install
3. Add your .env file with MONGO_URI and other keys
4. Run npm start
